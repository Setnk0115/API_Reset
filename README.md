# API Rest con node.js, express y prisma.

Este proyecto es sobre una API sencilla que permite manejar **users y tasks** conectados a una base de datos mediante prisma(Supabase). 

## Permite manejar (users y tasks) de esta manera:

### users

1. Create user
2. Get all users
3. Get user by id

## tasks

1. Create task
2. Get all tasks
3. Get tasks by id
